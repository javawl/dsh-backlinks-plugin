# 论坛（category: 论坛）

## 流程
1. 需要注册或登录 → 先走[登录决策树](../google-session.md)，用 interactive 快照识别 Google 等入口；走邮箱注册时用一次性邮箱 + mail_wait 验证。
2. 先完善个人资料：签名档（signature）里放锚文本+链接是最稳的论坛外链形态。
3. 若需发帖才显示签名：挑最匹配的版块发一篇**有真实价值**的帖子（提问/分享，不发广告贴——会被封）。群组/讨论式站点（如 Wix groups）没有签名档时，按博客剧本的"正文嵌链"把 `<a href="targetUrl">anchorText</a>` 直写进帖子正文（一段一链，核验同博客剧本）。
4. 发帖/设置签名后，打开自己资料公开页核验链接可见 → live。

## 边界
- 新号限制发链接（发帖数门槛）→ manual_required，说明门槛。
- 版规禁止外链 → skipped（规则）。
